# Digital Twin for Smart Farming in India

## Project Overview

This project aims to develop a Digital Twin-based Smart Farming system designed for Indian agricultural conditions.

The system creates a digital representation of farm information by combining soil reports, weather conditions, historical agricultural data, regional intelligence and machine learning-based predictions.

It provides farmers and agricultural support organisations with useful information to understand farm conditions and make better-informed farming decisions.

## Problem Statement

Farmers often face challenges in accessing and interpreting soil, weather and crop-related information. Agricultural data is available from different sources, making it difficult to analyse everything in one place.

There is a need for an integrated digital platform that combines this information and provides location-specific agricultural insights.

## Objectives

- Develop a digital representation of individual farms.
- Integrate soil, weather and agricultural datasets.
- Provide location-based agricultural information.
- Use machine learning for agricultural predictions.
- Present farm information through an accessible dashboard.
- Support better-informed agricultural decision-making.

## Key Features

- **Digital Farm Representation:** Virtual farm profiles, plots and farm maps.
- **Soil Intelligence:** Soil laboratory reports and mapped soil information.
- **Weather Monitoring:** Historical climate information and weather forecasts.
- **Regional Intelligence:** Location-based agricultural insights.
- **Crop Pattern Analysis:** Historical crop-pattern predictions.
- **Machine Learning:** Soil moisture forecasting and predictive analysis.
- **Farmer Support:** Farmer-friendly dashboard and assisted village services.

## Datasets Used

The project uses data from multiple sources:

- Government of India – Directorate of Economics and Statistics (DES).
- India District Crop Dataset (1997–2015).
- NASA POWER – Historical climate data.
- Open-Meteo – Weather forecast data.
- ISRIC SoilGrids – Soil information.
- Experimental Kolkata farm sensor dataset.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Visualisation:** Plotly.js
- **Maps:** Leaflet, OpenStreetMap
- **Deployment:** Docker

## Farm Area Measurement

Individual farm and plot areas are entered and displayed in square feet (sq ft).

Reference: 1 acre = 43,560 sq ft.

## Project Limitations

- SoilGrids provides mapped soil estimates, not actual farm laboratory measurements.
- Weather forecasts depend on external data services.
- Experimental moisture models are based on two Kolkata farm datasets.
- Crop-pattern predictions represent historical trends and are not guaranteed crop recommendations.
- The application is an academic prototype and not a fully integrated government agricultural service.

## Repository Contents

This repository includes project source code, datasets, machine learning models, documentation, research results and setup instructions.

## Project Purpose

To demonstrate how Digital Twin technology, data analytics and machine learning can be integrated to support smarter and more informed farming practices in India.
